# RAG 工具与运行指标实验

## 范围

本实验让真实聊天模型自主选择知识工具、执行真实 BGE 检索并生成回答。它不是完整 Supervisor 多 Agent 链路，不覆盖商品/订单/售后工具竞争、身份认证、人工接管或跨轮会话。

7 条开发者编写的诊断样本包含4条可回答政策问题、2条需拒答的具体价格/到账问题和1条问候。标签对照当前知识正文编写，但没有独立人工审核；不是原12条，也不是JDDC500条。样本同时用于开发与两轮实验，不属于独立测试集。知识工具只有一种，100%选择正确不代表多工具路由准确率。

## 实验环境

2026-10-10，聊天模型配置名称 deepseek-flash（服务商别名，不保证底层版本固定），本地 BAAI/bge-small-zh-v1.5，当前官方资料47块，BM25+BGE+RRF，向量过滤阈值0.32。Docker服务接口不可用，故使用隔离临时SQLite正文库和内存余弦检索；不修改业务数据库，不测Milvus/HNSW性能。生成与评审使用同模型不同调用，存在自评偏差。

## 指标定义

- 工具选择：逐样本判断需要知识时是否调用 search_knowledge，问候时是否不调用；分母7。
- 参数：Pydantic结构合法、可选分类与样本类别一致、查询保留至少一个标注关键事实词。一条任务的全部工具调用都需通过，分母为实际调用工具的6条任务。它是受控参数契约通过率，不是通用语义准确率；分类失配仍允许执行合法参数以观察模型修正。
- 任务通过：调用无错误、工具选择与参数契约通过，且模型评审正确性、忠实度、完整性均>=0.7；包含正确拒答与问候。失败和评审失败计未通过，分母7。这不是已完成订单等业务事务的完成率。
- P95：从首次模型调用到最终回答完成，包含工具选择、全部检索、再次调用和在线重试，不包含答案评审。只统计无运行错误的请求，同时报告数量。样本7条时最近秩P95实为最大值；无并发负载，不代表生产尾延迟。
- Token：仅使用服务端usage_metadata，汇总在线路径全部模型调用；评审不并入回答成本。缺失用量显示null，不通过字符数猜测。
- 费用：提供输入/输出每百万Token价格后估算；缺少价格或任一在线调用用量时显示null。不含评审、本地Embedding计算、缓存折扣、税费或完整多轮会话成本。

## 两轮真实结果

| 指标 | 第1轮 | 第2轮 |
| --- | ---: | ---: |
| 工具选择正确 | 7/7 (100%) | 7/7 (100%) |
| 参数契约通过 | 3/6 (50%) | 4/6 (66.67%) |
| 严格任务通过 | 4/7 (57.14%) | 5/7 (71.43%) |
| 端到端P95 | 4971.45 ms | 4193.71 ms |
| 在线输入Token总数 | 20245 | 19774 |
| 在线输出Token总数 | 3042 | 2892 |
| 费用 | 未提供单价 | 未提供单价 |

两轮使用相同样本，分别保存，不能选较好一轮作为正式成绩，也不能合并为14条独立测试样本。第二轮平均每次请求输入2824.86、输出413.14 Token；这只是小样本在线路径的均值。

失败主要暴露分类过滤不稳定：例如返修备份归到product_guide，而当前支持证据实际在return_policy；到款问题也可能先用售后类别，再纠正到payment_policy。严格参数指标会记录曾经错误的调用，即便最后回答正确。这里的分类标签也受知识组织方式影响，扩充参数评测时应标注允许类别集合并独立审核。

原始逐条输出和汇总已归档到 `docs/evaluations/rag-runtime-2026-10-10/`。没有重新标注或运行JDDC500的当前正式成绩，不复用旧95.45%指标。

## 如何运行

在backend目录激活项目虚拟环境后：

```powershell
python -m scripts.evaluate_rag_runtime --in-memory
```

Milvus恢复后去掉 `--in-memory`，会使用真实Milvus工具入口，需要另报后端和索引参数，不能将两类延迟混用。

费用参数为 `--input-price-per-million`、`--output-price-per-million` 和 `--cost-currency`。请填实际模型套餐价格，不提供默认价格；同一脚本不会以假价格冒充实际费用。

原有 `scripts.evaluate_rag` 同时新增逐条生成/评审用量、检索到答案完成P95及回答质量任务通过率。该入口直接检索，不衡量工具选择与参数。它的回答质量通过率不要求工具参数，与本脚本严格任务通过率口径不同。
