# RAG评测阶段报告

> 历史结果说明（2026-10-09）：本报告基于原演示知识文档。运行知识库现已替换为京东、淘宝官方页面的核验摘要；原来源标签、可回答性和参考答案需重新标注，本报告指标不代表新知识库效果。

> 当前检索算法已改为 BM25 + BGE 向量、RRF 等权排名融合。本报告中的关键词覆盖与加权混合结果属于旧算法，不代表新方案；尚未完成新知识库上的正式质量对比。

## 评测范围

本轮只评估知识检索和基于检索上下文的回答，不包含意图识别、业务工具调用、人工接管等
Agent能力。数据来自JDDC项目相关500条Query，并针对项目当前15个知识块进行两遍模型标注。

这500条记录的标注状态为`ai_verified`，表示经过两次独立模型提示审查，并不等同于人工金标准。
其中33条可以由当前知识库完整回答，467条需要拒答；19条标注置信度低于0.8。正式对外报告
指标前仍需对全部可回答样本和低置信度样本进行人工复核。

## 数据划分

- 开发集：300条，其中23条可回答；
- 验证集：100条，其中5条可回答；
- 测试集：100条，其中5条可回答。

JDDC与当前小型政策知识库的覆盖差异较大，因此必须分别观察可回答样本的召回率与不可回答
样本的错误召回率，不能使用单一总准确率掩盖类别不平衡。

## 全量500条混合检索诊断

本轮使用真实`BAAI/bge-small-zh-v1.5`生成向量，并通过`MilvusKnowledgeVectorStore`
执行余弦相似度检索。另使用内存向量存储进行过一次对照，两种后端在100条测试集上返回的
TopK来源逐条一致，没有发现来源或排序差异。

| 指标 | 结果 |
| --- | ---: |
| Recall@1 | 0.5000 |
| Recall@3 | 0.9242 |
| Recall@5 | 0.9545 |
| MRR | 0.7232 |
| 无答案拒答准确率 | 0.1520 |
| 无答案错误召回率 | 0.8480 |
| Milvus检索延迟P50 | 20.33ms |
| Milvus检索延迟P95 | 23.42ms |

结果表明，混合检索能够召回多数可回答问题，但当前`0.32`阈值在真实口语问题上明显过低，
大量知识库外问题仍然进入生成上下文。

暂不适合用于宣称方案具有稳定优势。重排在当前知识规模下没有收益，并显著增加延迟。

## 测试集回答效果

混合检索下对100条测试集进行了真实模型回答和独立模型评审：

| 指标 | 结果 |
| --- | ---: |
| 回答正确性 | 0.9800 |
| 回答忠实度 | 0.9810 |
| 回答完整性 | 0.9900 |
| 回答拒答准确率 | 0.9895 |
| 引用格式准确率 | 1.0000 |
| 引用支持度 | 0.9785 |

虽然检索对不可回答问题存在大量错误召回，回答模型仍在94/95条不可回答样本上正确拒答；
这不能代替检索层优化，因为无关上下文仍会增加幻觉风险和推理成本。5条可回答测试样本中有
1条被评为忠实度不足，需要人工复核回答与标注。

## 下一轮工作
