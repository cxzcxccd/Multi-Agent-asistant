# 官方知识来源

本次采集日期为 2026-10-09（北京时间）。`sources.json` 列出六个公开官方页面，五个来自京东帮助中心，一个来自淘宝官方消费者保障协议（阿里 CDN）。

资料是根据实际访问的页面制作的人工核验摘要，不是全文转载、商品页参数采集或官方授权数据接口。每份快照 JSON 保存来源 URL、适用范围、访问时间、可见文本 SHA-256 和少量核验片段；不保存完整网页。图片、登录页面及未核验内容不进入知识库。

在项目根目录执行：

```powershell
backend\.venv\Scripts\python.exe backend\scripts\import_official_knowledge.py
```

脚本仅访问清单中的官方 HTTPS 域名，处理京东 GBK 与淘宝 UTF-8 页面。先核验全部页面，再输出 Markdown 与知识来源清单。访问失败、登录页、关键片段缺失时中止；与已保存快照的可见文本哈希不同时也中止，需要人工比较原网页与摘要、更新来源快照后再导入。导航变化也可能触发哈希变化，不能自动判定政策改变。

运行时从 `backend/data/knowledge/sources.json` 读取有效文档清单。每个知识块都附平台、适用范围、原始 URL 和采集日期，原有 `文件名#章节` 引用仍可用。切块正文仍采用 500 字符与 60 字符重叠，来源元数据附加后长度可能超过 500。

导入后需重启后端（启动时自动同步索引），或由客服调用 `POST /api/staff/knowledge/reindex`。SQLite 与 Milvus 使用现有增量索引流程；成功同步后清理旧知识块和旧向量。Milvus 不可用时无法完成同步，请恢复服务后重试。

京东自营、服务标识权益与淘宝基础规则不能互相替代，也不自动成为演示店铺承诺。平台澄清目前依靠提示词，未实现检索层的强制平台过滤。没有采集具体商品页，因此商品数据仍是模拟数据；已移除没有真实来源的通用使用说明。

原有五份演示文档保留于 `backend/tests/fixtures/knowledge`，仅用于固定单元测试。12 条旧评测与 JDDC 500 条的来源标签、可回答性和参考答案依赖旧文档；历史报告仅代表旧知识库，不能作为新文档的指标。需重新标注后再正式评测。
